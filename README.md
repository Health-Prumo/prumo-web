# prumo-web

Front-end do **Prumo**, o coach de bem-estar com IA que responde "como estou hoje?". Projeto do FMU Tech Inovação 2026.2, ODS 3.

A proposta, a identidade visual e a arquitetura ficam no repositório central [Health-Prumo/prumo](https://github.com/Health-Prumo/prumo).

**Status:** em preparação para o Checkpoint 2. Stack definida: React + TypeScript (Vite) e Recharts. Detalhes para quem for contribuir (pessoas ou agentes de IA) em [AGENTS.md](AGENTS.md).
